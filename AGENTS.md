# Работа с нашим форком КОМПАС-3D MCP

Исходный проект: https://github.com/hymaxo/kompas3d-mcp.
Наш форк: https://github.com/babichvitaly/kompas3d-mcp.
Сохраняй MIT LICENSE и авторство исходного проекта.

## Среда и изменения

- Сервер работает в Windows рядом с КОМПАС через локальный stdio и COM.
  Рабочие исходники находятся в `src/kompas_mcp`, навыки — в `skills`.
- Перед CAD-операциями читай применимый навык `kompas-modeling`,
  `kompas-blueprints` или `kompas-api` и используй установленный SDK.
- COM-объекты принадлежат одному STA-потоку. Не передавай их между потоками.
- Проверки с КОМПАС запускай в интерактивном сеансе того же пользователя,
  что запустил КОМПАС. Сеанс SYSTEM не видит открытый пользовательский экземпляр.
- Не меняй пользовательский конфиг Codex целиком и не публикуй его.
- Соблюдай CONTRIBUTING.md. Для изменений кода запускай подходящие проверки:
  `uv run ruff check src tests scripts` и `uv run pytest -q`.
  Модульные тесты не подтверждают результат геометрических операций.

## Существующие модели и чертежи

- Перед изменением установи явный идентификатор, тип и путь документа.
- Работай с отдельной копией. Для сборок сначала проверь и скопируй зависимости:
  SaveAs одной сборки не защищает связанные детали от изменения.
- Сохраняй нативные операции, параметры и ссылки, когда задача этого требует.
  Не заменяй модель экспортированным телом без причины.
- Размеры — миллиметры, углы — градусы. Не придумывай критические размеры.
- Проверяй габариты, объём, число тел, видимое состояние и ошибки перестроения.
  Сохраняй и повторно открывай результат, если проверяется его пригодность.
- Не закрывай чужие несохранённые документы и не завершай процесс КОМПАС.
- Успешный ответ COM, количество видов и ненулевой размер файла недостаточны
  для подтверждения готовности чертежа.

## Известное ограничение

На нашей установке стандартные ассоциативные виды пока пустые.
`AddStandartViews` создаёт три записи; `Rebuild` и `RebuildViews` возвращают
True, но `ObjectCount=0` и `TreeNeedRebuild=True` сохраняются после открытия CDW.
Не выдавай такой чертёж как готовый. Подробности: `docs/local-development.md`.

## Публикация

Этот форк публичный. Не коммить реальные производственные модели, чертежи,
SDK, ключи, пользовательские настройки и логи с личными данными.
Используй синтетические примеры и обезличенные отчёты. Пользовательские данные
храни вне репозитория; игнорирование расширений — дополнительная защита.
