# Участие в разработке

Для разработки нужны Windows, Python 3.12 и uv. КОМПАС и его SDK нужны
только для проверок с настоящей CAD-системой.

```powershell
uv sync --locked
uv run ruff check src tests scripts
uv run pytest -q
uv build
```

Опишите проблему, версию и редакцию КОМПАС, ожидаемый результат и способ
воспроизведения. Перед публикацией удалите из логов личные пути и данные.
Не прикладывайте чужие чертежи, SDK или файлы с ограничениями на распространение.

Для изменений геометрии запускайте подходящий `scripts/validate_*.py` локально.
Эти сценарии запускают КОМПАС и создают документы. CI проверяет протокол и
валидацию без установленного КОМПАС и не подтверждает корректность геометрии.
Обновляйте `docs/coverage.md`, если меняется доказанное покрытие операций.

COM-объекты принадлежат одному STA-потоку. Не передавайте их между потоками.
Проверяйте результат через геометрию и сохранение/повторное открытие, когда это
существенно. Успешный возврат метода SDK сам по себе не доказывает результат.
