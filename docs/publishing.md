# Публикация на GitHub

Репозиторий подготовлен для публикации исходного кода. КОМПАС, его SDK,
сгенерированные COM-обёртки и локальные CAD-файлы не входят в дистрибутив.

Перед первой публикацией:

1. Лицензия MIT уже добавлена в `LICENSE`.
2. Выполните проверки из `CONTRIBUTING.md`.
3. Проверьте `git status --short` и состав будущего коммита.
4. Создайте пустой публичный репозиторий на GitHub и выполните команды,
   которые GitHub покажет для загрузки существующего локального репозитория.

Для первого коммита из корня проекта:

```powershell
git init -b main
git add .
git diff --cached --stat
git commit -m "Prepare initial public release"
```

После загрузки дождитесь успешного workflow Checks. Можно создать релиз
`v0.1.0` с указанием проверенной версии КОМПАС и известных ограничений.
GitHub автоматически предоставляет исходники в ZIP, включая установщик и skills.
Python wheel содержит сервер; для установки skills используйте полный архив
исходников или Git checkout. Публикация на PyPI не настроена.
